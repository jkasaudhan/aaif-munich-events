# What makes a good task for a coding agent?

*How to prepare datapoints you can trust when you develop an AI feature with evals*

**Speaker:** Evgenii Zakharchenko
**Event:** AAIF Community Munich #30

## About the talk

The talk covers eval-driven development, where you build an AI feature and its eval set together. A trustworthy datapoint has these parts: **Task · Environment · Checks · Judges · Controls**.

The workflow:

1. Define scenarios and success criteria
2. Write the first datapoints
3. Run a baseline eval
4. Change the skill, prompt or model
5. Run the eval again
6. Review errors and regressions, then repeat
